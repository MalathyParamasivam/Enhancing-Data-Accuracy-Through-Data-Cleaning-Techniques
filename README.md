# Enhancing-Data-Accuracy-Through-Data-Cleaning-Techniques
A data processing and analysis project leveraging Microsoft Excel to perform data cleaning, missing value handling, and conditional formatting for category-based product highlighting.
#  Excel Data Analysis Project

##  Overview
This project focuses on performing data analysis using Microsoft Excel. It includes data preprocessing, handling missing values, and applying conditional formatting to highlight specific product categories.

##  Objectives
- Identify and handle missing values in the dataset
- Perform data cleaning and preprocessing
- Highlight specific product categories (e.g., Electronics)
- Generate summary insights from the dataset

##  Tools & Techniques
- Microsoft Excel
- Conditional Formatting
- Logical Functions (IF, ISBLANK, etc.)
- Data Filtering & Sorting

##  Dataset
The dataset contains product-related information such as:
- Product Name
- Category
- Price
- Other relevant attributes

##  Process
1. Imported dataset into Excel
2. Checked for missing values in the price column
3. Applied formulas to handle missing data
4. Used conditional formatting to highlight specific categories
5. Created a summary for insights

##  Output
- Cleaned dataset with no missing values
- Highlighted product categories
- Summary report of key findings

##  Conclusion
This project demonstrates basic data analysis techniques using Excel, helping to understand data cleaning, transformation, and visualization.
